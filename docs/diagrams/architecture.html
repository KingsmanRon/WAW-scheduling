System map

ACCESS architecture

One Scheduling Core decides every booking, whoever asks and however they ask. Staff use the console in a browser, patients use WhatsApp, and both reach the same API, which writes to one database that refuses double bookings.

Vercel: the website Railway: the servers Supabase: data and sign-in People and outside services request sent in the background where the booking rules hold

How one booking travels

  1. A request arrives. Reception books on the console, or a patient taps a time on WhatsApp and Meta passes it to the API as a signed webhook.
  2. The API checks who is asking. The staff member's Supabase sign-in and practice role, or the patient's WhatsApp number and conversation.
  3. The Scheduling Core decides. It works out free times from working hours, leave and existing bookings, holds the time for five minutes, then books it.
  4. One database transaction saves it all. The appointment, its audit entry and its outbox event. If another request took the time a moment earlier, the database refuses this one and the person is offered other times.
  5. Everyone sees it. A Realtime signal tells every open console to refresh. Without Realtime, consoles refresh every 20 seconds.
  6. The worker follows up. It reads the outbox and sends the WhatsApp confirmation and reminders (only to patients who consented), e-mails, and EMR webhooks, retrying on failure.

What runs where

Host Runs
Vercel Front page and console: a static site built from apps/console. Holds only public settings.
Railway api, worker, migrate and clamav, all from the repository's one Docker image. Holds every secret.
Supabase PostgreSQL with all practice data, Auth for staff sign-in, Storage for referral documents, Realtime for live updates.
Meta The practice's WhatsApp number and its six approved message templates.

Each database login can do only its own job. The API and worker use separate logins limited by row-level security; only the migrate job holds the owner login. Staging and production are fully separate copies of all three hosts.
